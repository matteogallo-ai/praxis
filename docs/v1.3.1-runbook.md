# v1.3.1 runbook — abandoned

This file described a patch release, v1.3.1, meant to validate the v1.3.0
framing changes by re-scoring the 11 mock briefings with a Claude model and
gating the release on `framing_clarity ≥ 3.0`. That plan is abandoned and was
never run.

## Why

- **The scores would have measured the fixtures.** The mock provider replays
  hand-written fixtures selected by format, not by question. Between v1.2.1
  and v1.3.0 the four opening-section synthesis fixtures were rewritten by
  hand to lead with the decision (commit `1bb0b06`). Re-scoring them would
  have graded that hand edit, not the v1.3.0 prompts: no model output enters
  a mock briefing.
- **The gate could be passed by editing fixtures.** A threshold computed on
  hand-written text is met by writing better text, which is what had just
  happened.
- **The scorer and the system under test were the same model family**, with
  no human-labelled sample to check the scorer against.

Rule 3 of [`ENGINEERING_STANDARDS.md`](ENGINEERING_STANDARDS.md) now forbids
publishing a score computed on mock output, and `benchmarks/score-all.ts`
refuses to score mock briefings.

## What replaces it

The v1.3.0 prompt changes are evaluated on live briefings only, with the
method in [`benchmarking-methodology.md`](benchmarking-methodology.md), once
the live pipeline completes a briefing ([`CLAIMS.md`](CLAIMS.md) C14, C18).
