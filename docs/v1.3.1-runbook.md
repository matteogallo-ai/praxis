# v1.3.1 Runbook — Empirical Validation of v1.3.0

This runbook is the exact sequence to execute v1.3.1 when
Anthropic API credits are available. Total time: ~20 minutes.
Total cost: ~$1.

## Prerequisites

1. Anthropic API credits ≥ $5 (buffer over the $1 expected cost)
2. `ANTHROPIC_API_KEY` valid, in `.env` at repo root, gitignored
3. Repo at tag v1.3.0, working tree clean

Verify:

```bash
cd ~/dev/praxis
git status                       # clean
git describe --tags --abbrev=0   # v1.3.0
head -c 30 .env                  # ANTHROPIC_API_KEY=sk-ant-api03
```

## Sequence

### Step 1 — Re-score all 11 mocks against the v1.3.0 improved prompts (~$1)

```bash
export ANTHROPIC_API_KEY=$(grep ANTHROPIC .env | cut -d= -f2-)
bun run score --mock-only --refresh 01-german-market-entry,02-cfo-buyback-briefing,03-executive-succession-planning,04-uk-listing-board-briefing,05-supply-chain-acquisition,06-market-entry-southeast-asia,07-should-we-divest-consumer-line,08-ai-regulation-position,09-trade-association-response,10-esg-position,11-family-office-co-investment 2>&1 | tail -40
```

Expected output: 11 scored, 0 errors, aggregate
framing_clarity ≥ 3.0.

### Step 2 — Verify ship gates

```bash
cat benchmarks/RESULTS.md | grep -A 15 "Aggregate scores"
```

Ship gates from v1.3.0 ROADMAP:

- framing_clarity mock ≥ 3.0 (baseline v1.2.1 was 1.9)
- No other criterion regresses by more than -0.3 vs v1.2.1
  baseline

If either gate fails: **DO NOT tag v1.3.1**. Iterate on
`tone_directives` / `tone_hook` in one focused format, re-run
`bench:mock`, re-score, re-verify. Do not release with
underperforming metrics.

### Step 3 — Commit, tag, push

If ship gates pass:

```bash
# bump version
sed -i '' 's/"version": "1.3.0"/"version": "1.3.1"/' package.json
sed -i '' 's/PRAXIS_VERSION = "1.3.0"/PRAXIS_VERSION = "1.3.1"/' src/cli/version-constant.ts
# (update tests/cli/dispatch.test.ts manually — three occurrences)

# CHANGELOG entry — replace placeholders with real numbers from RESULTS.md
# (edit CHANGELOG.md manually, add [1.3.1] entry citing framing_clarity delta)

bun test                # verify baseline still 1216 pass
bunx tsc --noEmit       # 0 errors

git add benchmarks/RESULTS.md package.json src/cli/version-constant.ts tests/cli/dispatch.test.ts CHANGELOG.md
git commit -m "chore(release): v1.3.1 — empirical validation of v1.3.0 framing improvement"
git tag -a v1.3.1 -m "v1.3.1 — Empirical validation (framing_clarity: 1.9 → X.X)"
git push origin main
git push origin v1.3.1
```

Then create the GitHub release via the standard workflow
(Chrome extension or `gh` CLI).

## After v1.3.1

Praxis enters maintenance mode as documented in ROADMAP.md.
This runbook is not needed again.
